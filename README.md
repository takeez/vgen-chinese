# VGen 中文化

把 [vgen.co](https://vgen.co)（画师委托平台）的界面汉化成简体中文的**油猴脚本**。

> 纯**词库 + 正则**本地匹配，**不需要 AI 也能完整工作**。
> 可选接一个 OpenAI 兼容接口，用来辅助翻译还没收录的文案。

---

## 为什么要做成"词库"而不是"翻译插件"

VGen 上**大量文字是用户自己写的内容** —— 画师名、服务标题、委托描述、聊天消息。
通用翻译插件（不管是机器翻译还是大模型）会把这些也一起翻掉，
把 `I will draw your original character` 变成中文，那是**破坏数据**，不是本地化。

所以这里的做法是：**只翻"整条文本完全等于已知界面文案"的内容**。

- 词条是精确匹配，不是模糊匹配 —— 用户写的东西天然不会被碰
- 文案没收录就保持原样，等你补词条，而不是猜一个译文塞进去
- 词库是纯数据，可以版本化、可以 review、可以 PR

---

## 功能

| 功能 | 说明 |
|---|---|
| 界面汉化 | 约 2300 条词条 + 50 余条正则规则，覆盖导航、设置、委托流程、服务表单、钱包、编辑器 |
| **不误伤用户内容** | 整条精确匹配；另外有三个"用户内容区"类名直接跳过 |
| 字体修正 | 解决"中文看起来像繁体"——那是 VGen 字体栈里只有日文字体导致的（[详见开发笔记](./开发笔记.md)） |
| 自助翻译模式 | 鼠标点页面上的英文 → 填中文 → 立刻生效，词条存本地 |
| 忽略名单 | 判定"永不翻译"的文本（画师名等），不再被收集、不再出现在导出清单 |
| 可选 API 翻译 | 点「🤖 自动翻译」调 OpenAI 兼容接口译一条，**必须你再点保存才生效** |
| 词库在线更新 | 从本仓库直接拉最新词库，不用重装脚本 |

## 安装

1. 先装 **[篡改猴 / Tampermonkey](https://www.tampermonkey.net/)**。
2. **Chrome / Edge 必须额外做一步**：打开 `edge://extensions`（或 `chrome://extensions`），
   把左下角/右上角的 **「开发人员模式」打开**。
   MV3 之后篡改猴需要这个才能运行用户脚本；Edge 至今没有 Chrome 138+ 那个
   「允许用户脚本」开关，只能靠开发者模式。
3. 点这个链接安装：

   **https://raw.githubusercontent.com/takeez3/vgen-chinese/main/dist/vgen-chinese.user.js**

   若打开只显示一堆源码（说明第 2 步没生效），把整份内容复制，
   到篡改猴面板点「**+**（添加新脚本）」，全选替换后 `Ctrl+S`。
4. 打开 https://vgen.co 并刷新。

装好之后篡改猴会按脚本里的 `@updateURL` **自动检查更新**，不用手动维护。

## 使用

点篡改猴图标，菜单里是这些：

| 菜单项 | 作用 |
|---|---|
| ✅/⛔ **VGen 中文化** | 总开关（改完要刷新） |
| ✅/⛔ **正则翻译** | 关掉就只走精确词库 |
| ✅/⛔ **中文字体修正** | 见下面「字体问题」 |
| 📥 **更新词库** | 打开面板：在线更新 / 剪贴板更新 / API 配置 / 导出你的词条 |
| ✏️ **自助翻译模式** | 点页面上的英文来翻译 |
| 📋 **导出未命中词条** | 把"页面上的英文但词库没有"的清单导出来 |
| 🧹 **清空未命中记录** | 重新开始收集 |
| 🔄 **重新扫描当前页面** | 不刷新重跑一遍 |
| 📊 **显示状态** | 词条数 / 来源 / 版本 |

### 自助翻译模式

打开后：

1. 鼠标移到**还没翻译的英文**上 → 橙色描边
2. **点一下** → 弹出输入框（只显示原文，不会自动翻译）
3. 填中文 → 按回车或点「保存」→ **立刻生效**
4. 觉得这条永远不该翻 → 点「**不再提示**」，进忽略名单

词条存在篡改猴本地存储里。攒多了可以
「菜单 → 📥 更新词库 → ✏️ 导出我的自订词条」，提个 PR 或发 issue 合并进主词库。

### API 辅助翻译（可选）

在面板「🤖 API 翻译」里填 **端点 URL / API 密钥 / 模型名**，点「测试连接」验证。
之后自助翻译的弹窗里会多一个「🤖 自动翻译」按钮：

**点它才会调接口**，译文填进输入框让你过目，**再点保存才生效** ——
两步都要人点，不会自己去翻你没点的地方。

术语一致性靠每次请求附带一份从**现有词库**里自动挑选的相关术语表（glossary）来保证。

## 词库更新

| 方式 | 操作 |
|---|---|
| **在线（推荐）** | 面板 →「🌐 在线词库」→「立即更新」。默认从 GitHub raw 拉，失败会自动退到 jsDelivr 镜像 |
| **自动** | 同一处勾选「启动时自动检查」（默认关；12 小时一次，静默写入，下次开页面生效） |
| **剪贴板** | 面板 →「📥 从剪贴板读取并更新」，粘一份 `dist/vgen-dict.json` 格式的内容 |

**脚本本体和词库是分开的** —— 更新词库**不需要重装脚本**。

## 贡献词条

词库按主题拆在 `src/dict-*.js` 里，都是纯数据：

```js
var DICT_XXX = {
  'English on the page': '中文译文',
};
```

改完跑 `node build.mjs`，再跑 `node verify.mjs` 看覆盖率。

**加词条的注意事项：**

- 键必须和页面上显示的英文**一字不差**（首尾空白引擎会自己去掉）
- **值不能留空** —— 空译文会把页面文字整段抹掉，构建时会拒绝
- 引号不用纠结：引擎做了归一化，`’` 和 `'` 都能命中
- 带变量的文案（`12 days ago`、`Page 2 of 5`）写到 `src/regex.js`
- 用户内容（画师名、服务标题）**不要**加词条

完整的技术细节、踩过的坑、排查过程都在 **[开发笔记.md](./开发笔记.md)**。

## 字体问题（"中文看起来像繁体"）

VGen 的字体栈是：

```
Satoshi, Noto Sans JP, Noto Sans KR, Noto Sans TC, Arial, Tahoma, sans-serif
```

日文、韩文、繁体都有，**唯独没有简体**；而 `<html>` 上又没有 `lang` 属性。
浏览器按顺序匹配，撞上 `Noto Sans JP` 就停了 —— **所有中文都被用日文字形渲染**，
笔画看着就像繁体。**字符本身是简体的，是字形问题。**

脚本会把本机简体字体插到 `Noto Sans JP` 前面修掉它。副作用是**日文原文也会变成
简体字形**（CSS 没法按语言选字体），嫌别扭可以在菜单里关掉。

## 开发

```bat
cd vgen-chinese
node build.mjs          :: 产出 dist/vgen-chinese.user.js + dist/vgen-dict.json
node verify.mjs         :: 覆盖率自测
node verify-export.mjs "导出的清单.txt"
node probe.mjs          :: 关键回归用例
node make-fixture.mjs   :: 生成仿 VGen 的测试页
```

自测脚本通过 `harness.mjs` 从**打包产物里取出真引擎函数**来跑，
不是手抄一份复刻版 —— 这条踩过坑，见开发笔记。

```
src/
├─ head.js            油猴元数据
├─ normalize.js       引号归一化 / 大小写别名 / 空译文防线
├─ regex.js           正则词条
├─ engine.js          引擎：DOM 遍历、变更观察、忽略规则、字体、面板、菜单、API
└─ dict-*.js          词库（按主题分文件，纯数据）
```

## 已知限制

- **只翻界面，不翻用户内容**（刻意的）
- **动态内容保持英文**：别人发来的聊天消息、用户评论这类词库覆盖不了
- **依赖篡改猴 + 开发者模式**：Edge 大版本更新后开发者模式可能被重置，重新打开即可
- **有极少数文案翻不了**：VGen 在渲染前就用 JS 把字符串截断了
  （比如列表里显示成 `Character Re`），完整单词根本不在 DOM 里
- 权限要得比较多（`GM_xmlhttpRequest` 等），因为要跨域拉词库和调翻译接口
