# VGen 中文化

把 [vgen.co](https://vgen.co)（画师委托平台）汉化成简体中文的**油猴脚本**，
并且给中文画师补上"看得懂客户、写得回英文"这件事。

## 它解决什么问题

先说清楚两件不同的事，脚本也分成两条互不相干的通道：

| | 界面汉化 | 帮你跟客户沟通 |
|---|---|---|
| **原理** | 词库 + 正则，**本地匹配** | 调用你自备的 AI 接口 |
| **要不要联网** | 不要 | 要 |
| **要不要 API key** | **不要** | 要 |
| **花不花钱** | 不花 | 每次几厘到几分钱 |

**只装不用 AI，汉化也完全能用。** AI 那部分是可选加装。

---

## 界面汉化：为什么做成"词库"而不是"翻译插件"

VGen 上**大量文字是用户自己写的内容** —— 画师名、服务标题、委托描述、聊天消息。
通用翻译插件会把这些也一起翻掉，把 `I will draw your original character` 变成中文，
那是**破坏数据**，不是本地化。

所以汉化的做法是：**只翻"整条文本完全等于已知界面文案"的内容**。

- 词条是精确匹配，不是模糊匹配 —— 用户写的东西天然不会被碰
- 文案没收录就保持原样，等你补词条，而不是猜一个译文塞进去
- 词库是纯数据，可以版本化、可以 review、可以 PR

> 唯一例外是**你主动点**的地方（下面「AI」那一节）—— 你要是不点，它永远不动。

## 功能

### 汉化（不需要 API）

| 功能 | 说明 |
|---|---|
| 界面汉化 | 约 2400 条词条 + 77 条正则，覆盖导航、设置、委托流程、服务表单、钱包、编辑器、通知、接稿弹窗 |
| **不误伤用户内容** | 整条精确匹配；另有「用户内容区」类名直接跳过 |
| **动态文案** | 日期、时间、页码、计数这些拼接出来的（`Today at 7:15 AM`、`Page 1 / 2`、`3 hr ago`、`Aug 2026`）走正则，不是逐条加词 |
| 字体修正 | 解决"中文看起来像繁体"—— VGen 字体栈里只有日文字体（[详见开发笔记](./开发笔记.md)） |
| 自助翻译模式 | 点页面上的英文 → 填中文 → 立刻生效，词条存本地 |
| 忽略名单 | 判定"永不翻译"的文本（画师名等）不再被收集 |
| 词库在线更新 | 从本仓库直接拉最新词库，不用重装脚本 |

### AI 辅助（需要你自己的 API key）

> 全部**点击触发**，不会自己动，也不会自己发消息。

| 功能 | 位置 | 说明 |
|---|---|---|
| **客户需求翻译** | 接稿弹窗 →「附加信息」右上角「译」 | 客户自由填写的长文本（词库永远覆盖不了）。点一下就地变中文，边上的「EN」展开原文 |
| **聊天自动翻译** | 消息页 | 双方消息自动变中文（最近 50 条），每条右下角小「EN」展开原文；按消息 ID 缓存，同一段对话不重复付费 |
| **中文输入自动转英文** | 消息页输入框 | 打中文点发送 → **不发送**，内容就地变英文（可改）→ 再点一次才真发。带上下文，代词指代不会错 |
| **提案讨论窗口** | 提案标题旁「💬 讨论这单」 | 自动读整个接稿弹窗当背景（服务、授权、参考文件、截止日、你的条款…），多轮讨论后生成「范围」字段的英文 + 中文对照，一键填入 |
| 报价建议 | 同一个窗口「帮我估价」 | 只给**区间 + 依据 + 不确定项**，最终数字你自己填 |

**一条硬规则：发出去的永远是英文；你看到的永远默认中文；点「EN」才看原文。**
存进表单和发出去的内容，永远是英文原文。

## 安装

1. 先装 **[篡改猴 / Tampermonkey](https://www.tampermonkey.net/)**
2. **Chrome / Edge 必须额外做一步**：打开 `edge://extensions`（或 `chrome://extensions`），
   把 **「开发人员模式」** 打开（Edge 在**左下角**）。
   MV3 之后篡改猴需要这个才能运行用户脚本；Edge 至今没有 Chrome 138+ 那个
   「允许用户脚本」开关，只能靠开发者模式。
3. 点安装链接：

   **https://raw.githubusercontent.com/takeez/vgen-chinese/main/dist/vgen-chinese.user.js**

   若打开只显示一堆源码（说明第 2 步没生效），把整份内容复制，
   到篡改猴面板点「**+**（添加新脚本）」，全选替换后 `Ctrl+S`。
4. 打开 https://vgen.co 并刷新。

装好之后篡改猴会按 `@updateURL` 自动检查更新。

### 配置 AI（可选）

菜单 →「📥 更新词库」→ 展开「**🤖 API 翻译**」→ 填端点 / 密钥 / 模型 →「测试连接」

- 任何 **OpenAI 兼容**端点都行，默认 DeepSeek
- 密钥**只存在篡改猴本地存储**，脚本里不含任何 key（这是开源仓库，不能含）
- 旁边「📋 从剪贴板读配置」可以一次性导入 `{endpoint, key, model}`

## 已知限制

- **只翻界面，不自动翻用户内容** —— 除非你主动点「译」
- VGen 在渲染前就截断的字符串（列表里显示成 `Character Re`）**完整词不在 DOM 里**，翻不了
- `<option>` 只有带显式 `value` 的才会翻（没 value 的，提交值就是文本，翻了会改坏表单）
- `input` 的 `value` 属性一律不动（改了会破坏表单提交）
- Edge 大版本更新后开发者模式可能被重置，重新打开即可
